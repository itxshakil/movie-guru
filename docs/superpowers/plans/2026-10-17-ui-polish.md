# UI Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix every broken piece of the public UI and make it consistent through a small set of shared components and tokens, without changing page structure or features.

**Architecture:** New shared components live in `resources/js/Components/Ui/` (`UiButton`, `SectionHeading`, `UiChip`, `SelectInput`) with their class logic in a pure, Node-tested module.
Pages and components are migrated onto them task by task, each task verified by a DevTools-protocol screenshot script that also fails on horizontal overflow.
Icons are regenerated once from the master PNG by a small Pillow script.

**Tech Stack:** Laravel 13, Inertia 2, Vue 3.5, Tailwind 4, Pest 4, Node 22 `node --test`, Chrome headless over the DevTools protocol, Python 3 with Pillow (dev only, for icons).

**Spec:** `docs/superpowers/specs/2026-10-17-ui-polish-design.md`

## Global Constraints

- Never use the em dash character; use "-".
- Commit messages are conventional (`feat:`, `fix:`, `refactor:`, `style:`, `chore:`, `test:`, `docs:`) and carry no co-author line.
- Stage explicit paths only; never stage `.claude/`, `.github/`, `AGENTS.md`, `CLAUDE.md`, `boost.json`, `docs/growth-strategy.md` or any `.DS_Store`.
- Before every commit: `composer lint`, `php artisan test --compact`, `npm run test:js` and `npm run build` pass.
- Run `vendor/bin/pint --dirty --format agent` after touching PHP.
- No new npm or Composer dependencies.
- No decorative emoji in headings, labels or buttons; keep reaction emoji (👍 👎), mood tile emoji from the server, and notification, share and calendar text.
- No text below 11px; no `font-black`; no uppercase `tracking-widest` buttons.
- Every icon-only button has an `aria-label`; toggles use `aria-pressed`.
- Dark mode stays media-query based (`dark:` follows `prefers-color-scheme`).
- Match the surrounding file's style (4-space indent in Vue files, `<script setup>`).
- Local site: `http://movie-guru.test` on SQLite. Search and detail pages return the app's 503 fallback unless `OMDB_API_KEYS` holds a real key; then verify those pages on the live site after deploy and say so in the task report.

## Review Focus

1. A card's icon buttons and action buttons must not trigger the card link; a nested interactive element inside an `<a>` is invalid, so the card uses a stretched title link, not a wrapping `<a>`.
2. Ctrl, Cmd and middle click on a card must open a new tab on every width, including below 1024px where a plain click opens the quick-view sheet.
3. The phone tab bar must not cover content, toasts, the reaction prompt, the install banner or the detail page's sticky "Book tickets" bar.
4. Long titles (60+ characters), titles with no poster, no type, no rating and no director must render without empty pills, clipped descenders or layout jumps.
5. The home search pill must hold its children at 320px wide with the voice button, the clear button and the loading state.

```js
// Screenshots pages at phone and desktop widths in light and dark mode through the Chrome
// DevTools protocol, and fails when a page is wider than its viewport.
// Usage: node scripts/ui-screenshots.mjs <baseUrl> <outDir> [path ...]
import {spawn} from 'node:child_process';
import {mkdirSync, writeFileSync} from 'node:fs';
import {join} from 'node:path';

const CHROME = process.env.CHROME_BIN ?? '/Applications/Google Chrome.app/Contents/MacOS/Google Chrome';
const DEFAULT_PATHS = ['/', '/search?s=inception', '/i/tt1375666', '/watchlist', '/watchlist?tab=watched', '/mood',
    '/movie-match', '/contact', '/login', '/terms'];
const VIEWPORTS = {mobile: {width: 390, height: 844, mobile: true}, desktop: {width: 1440, height: 900, mobile: false}};
const SCHEMES = ['light', 'dark'];
const MAX_HEIGHT = 8000;

const [baseUrl, outDir, ...paths] = process.argv.slice(2);
if (!baseUrl || !outDir) {
    console.error('Usage: node scripts/ui-screenshots.mjs <baseUrl> <outDir> [path ...]');
    process.exit(2);
}
mkdirSync(outDir, {recursive: true});

const port = 9300 + Math.floor(Math.random() * 500);
const chrome = spawn(CHROME, ['--headless=new', '--disable-gpu', '--hide-scrollbars', `--remote-debugging-port=${port}`,
    `--user-data-dir=${join(outDir, '.profile')}`, 'about:blank'], {stdio: 'ignore'});

const sleep = (ms) => new Promise((resolve) => setTimeout(resolve, ms));

async function connect() {
    for (let attempt = 0; attempt < 50; attempt++) {
        await sleep(200);
        try {
            const targets = await (await fetch(`http://127.0.0.1:${port}/json`)).json();
            const page = targets.find((target) => target.type === 'page');
            if (page) {
                return page.webSocketDebuggerUrl;
            }
        } catch {
            // Chrome is still starting; the loop retries until the attempts run out.
        }
    }
    throw new Error('Chrome did not expose a page target');
}

const socket = new WebSocket(await connect());
await new Promise((resolve) => socket.addEventListener('open', resolve));
let nextId = 0;
const pending = new Map();
const listeners = new Set();
socket.addEventListener('message', (event) => {
    const message = JSON.parse(event.data);
    if (message.id && pending.has(message.id)) {
        pending.get(message.id)(message);
        pending.delete(message.id);
        return;
    }
    listeners.forEach((listener) => listener(message));
});
const send = (method, params = {}) => new Promise((resolve) => {
    const id = ++nextId;
    pending.set(id, resolve);
    socket.send(JSON.stringify({id, method, params}));
});

const OVERFLOW_PROBE = `(() => {
    const inScroller = (el) => { for (let p = el.parentElement; p; p = p.parentElement) {
        const o = getComputedStyle(p).overflowX; if (o === 'auto' || o === 'scroll' || o === 'hidden' || o === 'clip') return true; } return false; };
    const wide = [...document.querySelectorAll('body *')]
        .filter((el) => el.getBoundingClientRect().right > innerWidth + 1 && !inScroller(el))
        .slice(0, 10)
        .map((el) => el.tagName.toLowerCase() + (el.className && typeof el.className === 'string' ? '.' + el.className.trim().split(/\\s+/).slice(0, 3).join('.') : ''));
    return {innerWidth, scrollWidth: document.documentElement.scrollWidth, height: document.documentElement.scrollHeight, wide};
})()`;

await send('Page.enable');
let failed = false;
for (const path of paths.length ? paths : DEFAULT_PATHS) {
    for (const [viewportName, viewport] of Object.entries(VIEWPORTS)) {
        for (const scheme of SCHEMES) {
            await send('Emulation.setDeviceMetricsOverride', {width: viewport.width, height: viewport.height,
                deviceScaleFactor: 1, mobile: viewport.mobile});
            await send('Emulation.setTouchEmulationEnabled', {enabled: viewport.mobile});
            await send('Emulation.setEmulatedMedia', {features: [{name: 'prefers-color-scheme', value: scheme}]});
            const loaded = new Promise((resolve) => {
                const onLoad = (message) => {
                    if (message.method === 'Page.loadEventFired') {
                        listeners.delete(onLoad);
                        resolve();
                    }
                };
                listeners.add(onLoad);
            });
            await send('Page.navigate', {url: new URL(path, baseUrl).href});
            await Promise.race([loaded, sleep(20000)]);
            await sleep(2500);

            const probe = (await send('Runtime.evaluate', {expression: OVERFLOW_PROBE, returnByValue: true})).result.result.value;
            const overflow = probe.scrollWidth > probe.innerWidth ? probe.wide : [];
            failed ||= overflow.length > 0 || probe.scrollWidth > probe.innerWidth;
            console.log(JSON.stringify({path, viewport: viewportName, scheme, scrollWidth: probe.scrollWidth,
                innerWidth: probe.innerWidth, overflow}));

            const shot = await send('Page.captureScreenshot', {format: 'png', captureBeyondViewport: true,
                clip: {x: 0, y: 0, width: viewport.width, height: Math.min(probe.height, MAX_HEIGHT), scale: 1}});
            const slug = path.replace(/[^a-z0-9]+/gi, '-').replace(/^-|-$/g, '') || 'home';
            writeFileSync(join(outDir, `${slug}-${viewportName}-${scheme}.png`), Buffer.from(shot.result.data, 'base64'));
        }
    }
}

chrome.kill('SIGKILL');
process.exit(failed ? 1 : 0);
```

```js
const BASE = 'inline-flex items-center justify-center gap-2 rounded-xl font-semibold transition-colors press-spring '
    + 'focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-primary-500 '
    + 'disabled:pointer-events-none disabled:opacity-60';

const VARIANTS = {
    primary: 'bg-primary-600 text-white shadow-sm hover:bg-primary-500 active:bg-primary-700',
    secondary: 'bg-gray-100 text-gray-900 hover:bg-gray-200 dark:bg-gray-800 dark:text-white dark:hover:bg-gray-700',
    ghost: 'bg-transparent text-gray-700 hover:bg-gray-100 dark:text-gray-200 dark:hover:bg-gray-800',
    danger: 'bg-red-600 text-white shadow-sm hover:bg-red-500 active:bg-red-700',
};

const SIZES = {
    sm: 'px-3 py-1.5 text-xs',
    md: 'px-4 py-2.5 text-sm',
    lg: 'px-6 py-3 text-base',
};

const CHIP_BASE = 'inline-flex items-center gap-1.5 rounded-full border font-medium transition-colors';
const CHIP_SIZES = {sm: 'px-2 py-0.5 text-[11px]', md: 'px-3.5 py-1.5 text-sm'};

export function buttonClasses({variant = 'primary', size = 'md', block = false} = {}) {
    return [BASE, VARIANTS[variant] ?? VARIANTS.primary, SIZES[size] ?? SIZES.md, block ? 'w-full' : ''].join(' ').trim();
}

export function buttonTag({href, disabled} = {}) {
    return href && !disabled ? 'link' : 'button';
}

export function chipClasses({active = false, size = 'md', interactive = true} = {}) {
    const colours = active
        ? 'border-primary-600 bg-primary-600 text-white'
        : 'border-gray-200 bg-white text-gray-700 dark:border-gray-700 dark:bg-gray-900 dark:text-gray-300';
    const hover = interactive && !active
        ? 'hover:border-primary-400 hover:text-primary-700 dark:hover:border-primary-500 dark:hover:text-white'
        : '';
    return [CHIP_BASE, CHIP_SIZES[size] ?? CHIP_SIZES.md, colours, hover].join(' ').trim();
}
```

- [ ] **Step 1: Write the script**

```python
"""Crops the black frame from the master app icon and rewrites every icon at its current size.

Dev-only tool; needs Python 3 and Pillow (`python3 -m pip install Pillow`).
Usage: python3 scripts/regenerate-icons.py
"""
from pathlib import Path

from PIL import Image

ROOT = Path(__file__).resolve().parent.parent
MASTER = ROOT / 'public/icons/ios/1024.png'
ICON_DIRS = [ROOT / 'public/icons/ios', ROOT / 'public/icons/android', ROOT / 'public/icons/windows11']
FAVICON = ROOT / 'public/favicon.ico'
DARK_THRESHOLD = 30


def frame_bounds(image: Image.Image) -> tuple[int, int, int, int]:
    """Returns the box of the first non-black pixels, scanning in from each edge along the
    quarter lines, where the film strip does not reach the frame."""
    width, height = image.size
    probe_x, probe_y = width // 4, height // 4

    def is_dark(x: int, y: int) -> bool:
        return sum(image.getpixel((x, y))[:3]) < DARK_THRESHOLD

    left = next(x for x in range(width) if not is_dark(x, probe_y))
    right = next(x for x in range(width - 1, -1, -1) if not is_dark(x, probe_y)) + 1
    top = next(y for y in range(height) if not is_dark(probe_x, y))
    bottom = next(y for y in range(height - 1, -1, -1) if not is_dark(probe_x, y)) + 1
    return left, top, right, bottom


def main() -> None:
    master = Image.open(MASTER).convert('RGB')
    box = frame_bounds(master)
    if box == (0, 0, *master.size):
        raise SystemExit('No frame found; the master icon is already cropped.')
    tile = master.crop(box)
    print(f'Cropped frame {box} from {MASTER.name}')

    for directory in ICON_DIRS:
        for path in sorted(directory.glob('*.png')):
            with Image.open(path) as current:
                size, mode = current.size, current.mode
            side = min(size)
            resized = tile.resize((side, side), Image.LANCZOS)
            canvas = Image.new('RGBA' if mode == 'RGBA' else 'RGB', size, (0, 0, 0, 0) if mode == 'RGBA' else (0, 0, 0))
            canvas.paste(resized, ((size[0] - side) // 2, (size[1] - side) // 2))
            canvas.convert(mode if mode in ('RGB', 'RGBA') else 'RGBA').save(path, optimize=True)
            print(f'Wrote {path.relative_to(ROOT)} {size[0]}x{size[1]}')

    tile.save(FAVICON, sizes=[(16, 16), (32, 32), (48, 48)])
    print(f'Wrote {FAVICON.relative_to(ROOT)}')


if __name__ == '__main__':
    main()
```
